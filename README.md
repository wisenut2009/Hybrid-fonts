说明：

1）不是直接用于替换系统自带的宋体，而是用于MacType热替换宋体，护眼。

常规、斜体、粗体和粗斜体字形的宽度都与宋体一致，不会改变Word文档版面。这样，查看他人发过来的Word文档，以及他人查看自己修改过的Word文档，双方看到的版面都是一致的。

测试了新晰黑（SimXiHei）、新致宋（SimZhiSong）、霞鹜新晰黑 屏幕阅读版 补全（LXGWNeoXiHeiScreenFull）、霞鹜新致宋 屏幕阅读版 补全（LXGWNeoZhiSongScreenFull）、梦源黑体（梦源黑体  CN W9 ）、思源黑体 VF（Source Han Sans SC VF）、文渊黑体、文渊黑体C、文渊宋体、文津宋体（文津宋体C 第0平面 ）、霞鹜文楷 Consolas Mono，效果都不好，要不因行间距变化、英文宽度不一致、或粗体/粗斜体与常规/斜体宽度相同导致MSWord版面变化（宋体的粗体和粗斜体字形比常规和斜体更宽一点），要不字重太浅、字形不美观。霞鹜新晰黑、霞鹜新晰黑+、霞骛新致宋、霞骛新致宋+，则完全没有热替换效果。

2）用于各种开发工具也是完全可以的。因为中英文字符完全2:1，且中文字符间距正常，不会稀稀拉拉，比一般的Fontlink方案视觉效果更好。
